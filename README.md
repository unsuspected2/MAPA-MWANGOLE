Visão Geral
Este mapa interativo apresenta as 21 províncias de Angola de forma dinâmica e informativa. Desenvolvido com tecnologias web modernas (HTML, CSS e JavaScript), o mapa permite aos usuários explorar cada província com detalhes relevantes.

Principais Características
Interatividade
Efeito Hover: As províncias mudam de cor quando o cursor passa sobre elas

Tooltips Informativos: Mostram dados essenciais ao passar o mouse:

Nome da província

Capital

Área territorial

População estimada

Responsividade: Design adaptável para diferentes tamanhos de tela

Visualização de Dados
Cada província é representada com cores distintas

Legenda explicativa das cores utilizadas

Nomes das províncias destacados no mapa

Dados Técnicos
Desenvolvido com SVG para gráficos vetoriais de alta qualidade

Animações suaves em CSS para transições

Estrutura semântica HTML5

Funcionalidades Adicionais
Efeitos visuais ao selecionar uma província

Possibilidade de integração com sistemas de geolocalização

Arquitetura preparada para adicionar mais funcionalidades (como rotas de navegação entre províncias)

Este mapa é ideal para aplicações educacionais, governamentais ou turísticas, proporcionando uma experiência rica e informativa sobre a divisão territorial de Angola.
